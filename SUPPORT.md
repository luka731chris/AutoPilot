# Support

Start with [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

When documenting a bug, include:

- app version;
- browser/device;
- calendar provider type (Apple/TeamSnap/GameChanger/etc.);
- expected behavior;
- actual behavior;
- sanitized sample event details if needed.

Never include the actual calendar subscription URL or a real backup file in a public issue.
