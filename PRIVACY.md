# Privacy Notice

This project is a private family logistics tool. The core static application stores configuration and imported planning data in browser local storage. It does not require a hosted application database.

Calendar subscription links, planner backups, generated mobile agendas, and printed schedules can reveal sensitive household logistics. Treat them as private.

For detailed handling guidance, see [docs/PRIVACY-AND-DATA.md](docs/PRIVACY-AND-DATA.md).
